# ホーム画面への追加

## 追加する

- スマホのブラウザ（iPhone の Safari、Android の Chrome）の「ホーム画面に追加」（Android では「アプリをインストール」とも出る）で、ホーム画面に追加できる。アプリの中に、追加を勧めるボタンや案内はない
- ホーム画面に出る名前は「md-leaf」。アイコンは、アプリの印の若葉（ノートの一覧の上の印と同じ形）を、ダークの accent の色で、ダークの bg（黒系）の地の中央に置いたもの。ライト・ダークで変わらない
- アプリの名前・アイコン・色の情報（マニフェスト `/manifest.webmanifest` と、アイコンの画像 `/icon/192`・`/icon/512`・`/apple-icon`、ブラウザのタブのファビコン `/icon/32`）は、ログインしていなくても読める。ほかの URL は今と同じくログインが要る（`docs/specs/login.md`）

## ホーム画面から開く

- ホーム画面のアイコンから開くと、アドレスバーなどのブラウザの枠がない全画面で、ホーム（`/`）が開く。ログインしていなければ、全画面のままログインの画面が出る（`docs/specs/login.md`）
- 全画面のまま、アプリの中を移れる（ノートの一覧・ノートの中の相対リンク・目次・文字の大きさ・テーマ・ログアウト）。画面の向きは固定しない
- スマホの上の、時刻や電池が出る部分には、上の帯や本文が隠れない（ブラウザがその部分をよけて描く）
- 時刻や電池が出る部分の色は、そのときの画面の地（bg）。テーマを選んだとき・「端末に合わせる」で端末の設定が変わったときも、それに合わせて変わる（ブラウザが対応している場合）。ログインの画面でも同じ
- Android では、画面のいちばん下（ジェスチャーの横線が出る部分）の帯と、開いた直後の画面は、ダークの地（bg）の色。ライトのときも変わらない（ブラウザがマニフェストの色で塗り、アプリの中から変えられないため。色は1つしか決められず、ダークで帯が目立たないほうを選んだ）
- 電波がないときは、ブラウザがいつも出す「つながりません」の画面になる（アプリの中にノートを残さない）
- アプリの中の画面の見た目は、ブラウザで開いたときと同じ
