---
name: content-review
description: content/ の教材のフォルダ（または1つのノート）を、サブエージェント content-reviewer に精査させ、指摘の一覧を返す（ノートは変えない）
argument-hint: <content/ の教材のフォルダかノート>
disable-model-invocation: true
---

コマンドのあとに書かれた教材のフォルダ（またはノート）の中身を精査する。精査の観点は `docs/content-rules.md` の「精査の観点」。**ノートは変えない**（ノートの正本は Obsidian の保管庫にあり、直すのは人が保管庫のほうで行う）。

1. 引数がなければ、`content/` の一番上にある教材のフォルダの一覧を示し、どれを精査するか聞いて止まる
2. 引数のパスが `content/` の下にあり、教材のフォルダかノート（`.md`）であることを確かめる。そうでなければ、そう伝えて止まる
3. サブエージェント `content-reviewer` に、パスを渡して精査してもらう
4. 返った一覧（「指摘なし」のときはそのまま）を、まとめ直さずに人に伝える。指摘を直さない
   - 決まりに合わないもの（ファイル名・リンク切れなど）は精査では見ないので、まだなら `npm run check:content` を流すよう添える

サブエージェントを使えない場合は、`.claude/agents/content-reviewer.md` を読み、同じことを自分で行って、同じ形で返す。そのときも、ファイルを変える道具は使わない。
